# Задание 6.3. Калькулятор с динамической загрузкой плагинов

## Назначение

Калькулятор обнаруживает математические операции в каталоге `plugins` и загружает их из отдельных динамических библиотек `.so`. Меню формируется из доступных плагинов при каждом запуске приложения.

## Организация проекта

- `main.c` — меню, ввод чисел и вызов выбранной операции.
- `loader.c`, `loader.h` — обнаружение плагинов, загрузка и освобождение библиотек.
- `plugin_api.h` — общий интерфейс математического плагина.
- `plugins/add.c` / `add.so` — сложение.
- `plugins/subtract.c` / `subtract.so` — вычитание.
- `plugins/multiply.c` / `multiply.so` — умножение.
- `plugins/divide.c` / `divide.so` — деление.
- `Makefile` — сборка основного приложения и всех четырёх плагинов.

Загрузчик использует `opendir()`/`readdir()` для поиска файлов, `dlopen()` для загрузки, `dlsym()` для получения указателя на функцию `calculator_plugin()` и `dlclose()` для освобождения ресурсов.

## Сборка и запуск

```bash
make clean
make
ls -l plugins/*.so
./calculator
```

По умолчанию плагины ищутся в `./plugins`. Каталог можно указать явно:

```bash
./calculator ./plugins
```

Номера математических операций формируются при запуске и могут отличаться; ориентируйтесь на название команды в меню.

## Проверка арифметических операций

Выберите соответствующие пункты меню и проверьте:

- Сложение: `15` и `25` → `40`.
- Вычитание: `9` и `4` → `5`.
- Умножение: `6` и `7` → `42`.
- Деление: `20` и `4` → `5`.
- Деление на ноль: `20` и `0` → сообщение о невозможности операции.

Выход из калькулятора — пункт `0`.

## Проверка отключения отдельной библиотеки

1. Убедитесь, что в первоначальном меню есть операция сложения. Завершите программу пунктом `0`.
2. Удалите библиотеку сложения:

```bash
rm plugins/add.so
ls plugins/*.so
```

3. Не выполняя `make`, запустите готовый калькулятор:

```bash
./calculator
```

Ожидаемый результат: калькулятор запускается, пункт сложения отсутствует, остальные операции продолжают работать. Проверьте, например, умножение `6 × 7 = 42`.

4. Завершите программу и восстановите только удалённую библиотеку:

```bash
make plugins/add.so
./calculator
```

Ожидаемый результат: сложение вновь отображается в меню и выполняет вычисление `15 + 25 = 40`.

## Дополнительная проверка расширяемости

Для создания нового плагина можно использовать `plugins/add.c` как образец: создать другой `.c` с реализацией интерфейса из `plugin_api.h`, присвоить новое имя операции и скомпилировать в отдельную `.so`. Основное приложение при этом менять и пересобирать не требуется.

Команда для сборки нового плагина `plugins/extra.c`, если этот файл создан:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -fPIC -shared plugins/extra.c -o plugins/extra.so
./calculator
```

Новый плагин появится в меню при следующем запуске. Порядок перечисления плагинов и номера пунктов могут меняться.

## Особенности

- Отсутствие одной библиотеки отключает только её математическую операцию.
- Остальные загруженные плагины продолжают работать.
- Не вызывайте `make` непосредственно перед проверкой удаления: отсутствующий плагин может быть собран заново.
