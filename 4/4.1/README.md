# Задание 4.1. Телефонная книга на двусвязном упорядоченном списке

## Назначение

Программа хранит контакты в двусвязном упорядоченном списке. Для контакта предусмотрены ФИО, место работы, должность, телефоны, электронные адреса, ссылки на социальные сети и профили мессенджеров. Фамилия и имя обязательны; остальные данные вводятся при необходимости.

## Организация проекта

- `main.c` — меню, ввод и вывод данных.
- `contacts.h` — структуры и объявления функций.
- `contacts.c` — операции со списком: добавление, поиск, изменение, удаление и сортировка.
- `Makefile` — сборка программы.

Элементы хранятся в отдельных узлах, связанных указателями `prev` и `next`. При добавлении и изменении контакта поддерживается выбранный порядок. При удалении связи соседних узлов восстанавливаются, память узла освобождается.

## Сборка и запуск

Требуются Linux, GCC и Make. В каталоге задания выполните:

```bash
make clean
make
./phonebook
```

## Проверка функциональности

1. Выберите `1` и добавьте контакты в следующем порядке: Васильев Иван, Алексеев Пётр, Борисов Олег. Остальные поля можно пропускать клавишей Enter.
2. Выберите `2`: при сортировке по фамилии по возрастанию контакты должны отображаться в порядке Алексеев, Борисов, Васильев, независимо от порядка ввода.
3. Выберите `5`. Программа предлагает поле сортировки (`1` — фамилия, `2` — имя, `3` — место работы) и направление (`1` — возрастание, `2` — убывание). Установите сортировку фамилий по убыванию. Проверьте новый порядок пунктом `2`.
4. Выберите `3` и отредактируйте существующий контакт. Пунктом `2` проверьте обновлённые данные.
5. Выберите `4`, укажите контакт и подтвердите удаление. Убедитесь через пункт `2`, что контакт отсутствует.
6. Выберите `0`, чтобы завершить программу.

## Особенности

- Используется собственная реализация двусвязного списка, без готовых библиотек контейнеров.
- Узлы создаются и освобождаются динамически.
- Сортировка задаёт порядок элементов списка, а не только порядок их отображения.
- Данные существуют в оперативной памяти в течение работы программы; сохранение в файл не предусмотрено.
