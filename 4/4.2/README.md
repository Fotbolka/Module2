# Задание 4.2. Очередь сообщений с приоритетами

## Назначение

Программа реализует очередь сообщений с приоритетами от 0 до 255. Значение 255 соответствует максимальному приоритету. При одинаковом приоритете соблюдается порядок поступления сообщений (FIFO).

## Организация проекта

- `main.c` — пользовательское меню, ввод, генерация сообщений и вывод результатов.
- `queue.h` — описание данных и интерфейса очереди.
- `queue.c` — добавление и извлечение элементов, управление памятью.
- `Makefile` — сборка.

Очередь реализована на связном списке, упорядоченном по убыванию приоритета. Сообщение с наибольшим приоритетом находится в начале.

## Сборка и запуск

```bash
make clean
make
./priority_queue
```

## Проверка функциональности

1. Пунктом `1` добавьте четыре сообщения в порядке: `низкий` (приоритет 10), `обычный-1` (100), `срочный` (255), `обычный-2` (100). В меню отображается текущее количество элементов.
2. Выберите `3`. Первым должно извлечься сообщение `срочный` с приоритетом 255.
3. Выберите `4`, укажите приоритет `100`. Должно извлечься `обычный-1`. Повторите пункт `4` с приоритетом `100`: извлечётся `обычный-2`. Это демонстрирует FIFO среди сообщений одинакового приоритета.
4. Выберите `5`, укажите минимальный приоритет `50`. Если в очереди остался только элемент с приоритетом 10, программа сообщит, что подходящего сообщения нет.
5. Выберите `3` ещё раз: извлечётся оставшееся сообщение с приоритетом 10. Повторное извлечение из пустой очереди выдаёт сообщение об отсутствии подходящего элемента.
6. Пунктом `2` создайте, например, 5 сообщений со случайными приоритетами; программа выведет созданные сообщения.
7. Выберите `0` для завершения.

## Особенности

- `queue_push()` вставляет новый элемент с учётом приоритета.
- `queue_pop_first()` извлекает первый элемент очереди.
- `queue_pop_exact()` извлекает элемент заданного приоритета.
- `queue_pop_at_least()` извлекает элемент с приоритетом не ниже порога.
- `queue_clear()` освобождает оставшиеся элементы.
- В текущей версии нет отдельной команды просмотра всей очереди без извлечения элементов.
